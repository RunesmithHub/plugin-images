# The image viewer

PNG, JPEG, WebP, GIF, BMP and ICO files open in the image viewer. It shows the image on a checkerboard where it is transparent, and its
format, size in pixels and file size above it. A GIF shows its first frame.

| Action | Mouse | Keys |
| --- | --- | --- |
| Zoom in or out at the pointer | Wheel | <Keys>+</Keys> and <Keys>-</Keys>, at the center |
| Fit the image in the tab | **Fit** | <Keys>0</Keys> |
| Show the image at its actual size | **1:1** | <Keys>1</Keys> |
| Switch between fitted and actual size | Double-click | |
| Move a zoomed image | Drag | |

A fitted image is never shown larger than its actual size, and it follows the tab's size. Pixels show as sharp squares from 200% up. When
the file changes on disk, the viewer shows the new version.
